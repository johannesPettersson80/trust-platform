# Web UI Complete Project

Docs category: `docs/public/examples/capstones.md`

This example is a fuller web-UI oriented project than the tutorial-scale examples.

Use it when you want:

- a project with `src/`, `io.toml`, and `simulation.toml`
- a web-facing runtime surface (the browser IDE at `/ide`)
- something closer to a capstone than a tutorial

See also:

- `docs/public/start/program-in-browser.md`

## Screen

`hmi/pages/overview.toml` shows this example's values. It opens in the HMI Builder in VS Code; press **Live** while the simulator runs to see the values move. The runtime also serves it at <http://127.0.0.1:8080/hmi>.
