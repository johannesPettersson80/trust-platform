### Added

- `method.call` calls a method of a function block between two scans, as a screen's command calls
  one: a machine test presses a sequence's Start with it. The request names the instance by its
  path, the interface, the method and its inputs as Structured Text literals, each typed by its
  input's declared type as `set` types a value, and answers the method's result. Every runtime
  answers it alike, a computer and a chip. A method that faults faults the resource as a faulted
  scan does, and a stopped or faulted resource refuses the call (specification 11, "Calling a
  method").
