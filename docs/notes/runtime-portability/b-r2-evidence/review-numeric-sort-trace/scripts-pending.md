Read-only source review; scripts were not executed or syntax-checked. Preparation is single-use, formats once, preserves both lockfiles/artifacts and freezes modified/untracked/deleted paths. M2 now checks exact manifest approval before consuming its once-only marker, retains failed-link maps, and reports missing maps/failed attribution as failure. Final software batch deduplicates runtime vertical into integration suites, includes native new tests through owning suites, i686 and MCU checks, both audit graphs, lint, architecture before diagrams, provenance, format and immutable artifact checks. Independent failures continue; dependent rendering/inspection remain unrun. No firmware relink occurs in that batch.

Board script pending correction: `flash write_image erase firmware.elf` can erase sector holes inside one flash bank, violating checkpoint preservation for a sector-0 plus upper-region ELF. The official OpenOCD manual documents this behavior: https://openocd.org/doc/html/Flash-Commands.html . Root notified to explicitly erase sector 0 and sectors 4..7, then write the ELF without automatic erase; application sector 1 is separately erased/written. Before/after comparisons remain required, but cannot substitute for preventing the destructive gap erase. Source approval cannot certify actual board behavior.
