# Phase 10 - Trust-Dev Alias Removal Window

Date: 2026-07-05

## Scope

Phase 10 keeps the existing `trust-runtime` workbench compatibility aliases in
place, but makes their compatibility policy explicit and machine-checked:

- Canonical commands are `trust-dev test`, `trust-dev docs`,
  `trust-dev commit`, and `trust-dev agent serve`.
- Deprecated aliases are `trust-runtime test`, `trust-runtime docs`,
  `trust-runtime commit`, and `trust-runtime agent serve`.
- Alias removal is not allowed before 2026-10-05.
- Alias removal requires a separate behavior-change release note.

This phase does not remove the aliases.
