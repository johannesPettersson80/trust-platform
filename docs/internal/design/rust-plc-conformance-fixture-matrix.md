## Fixture Rules

- Fixture names are stable once committed.
- Each fixture states expected F row, RS references, and owning slice.
- Negative fixtures assert the exact diagnostic code and key message terms.
- VS Code fixtures consume the same JSON/control payload as runtime tests.
- Generated artifacts inside fixtures are regenerated by commands, not hand
  patched.
- CI grouping keeps quick tests fast and full conformance comprehensive.
