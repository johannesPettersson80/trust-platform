# Capstones

Use capstones when you want to see multiple truST surfaces working together in
one larger project instead of learning one feature at a time. Start here after
the basic tutorials if you want a concrete end-to-end plant-style demo.

You should leave this page understanding how source, runtime config, HMI files,
and operator surfaces fit together in one project. Budget 20-30 minutes for a
first read and longer if you run every command. Read
[First Project](../start/first-project.md) first if you have not yet opened a
shipped tutorial. Success means you can name the project files that drive the
runtime and the browser view.

Use this after the workflow tutorials, not as the first page for installation or
editor setup.
