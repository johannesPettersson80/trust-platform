# Tutorials

Follow the tutorial sequence from basic editing through runtime, HMI, and
deployment workflows.

The tutorial path is ordered for confidence:

1. basic ST editing
2. control/runtime interaction
3. tests and validation
4. deployment, observability, HMI, and integration surfaces

Use this page when you want the guided path rather than a catalog. After the
first tutorial, you should have seen editor diagnostics, runtime execution,
HMI/browser surfaces, and at least one validation loop before moving to a
custom project.

Budget 45-90 minutes for the full path, or 10-20 minutes for one tutorial.
Success means you can pick the next tutorial by workflow rather than opening
example folders at random.

Use [Learning Paths](learning-paths.md) first if you want a goal-based sequence
instead of the complete tutorial catalog.
