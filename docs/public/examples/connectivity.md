# Connectivity

Use this page when your next question is how truST talks to other runtimes,
external systems, or device backends. The example pack below is the runnable
companion to the Connect section. After reading it, you should know which
example maps to MQTT, OPC UA, Modbus, GPIO, multi-driver, or runtime-to-runtime
work before opening a protocol-specific page.

Budget 15-25 minutes to choose the right example, then more time for target
network or hardware validation. Prerequisite: read
[Communication Planes](../concepts/communication-planes.md) or
[Protocol Matrix](../connect/protocol-matrix.md) if you are not sure which
endpoint you are connecting to. Success means you can pick one example, explain
the protocol boundary, and name the config file that must be reviewed before
deployment.
