# Runtime Cloud

Use this page when you want a runnable runtime-cloud example before reading the
full federation and operation guides. It is for topology and deployment shape,
not local single-runtime authoring. After reading it, you should know which
files form the example topology and which Operate/Connect pages explain daily
use versus architecture.

Budget 20-30 minutes for the example and a separate review for credentials,
firewall, and rollout policy. Prerequisite: read
[Runtime Cloud Federation](../connect/runtime-to-runtime/runtime-cloud-federation.md)
if the topology crosses a site boundary. Success means you can point to the
example profile, the node roles, and the operator page that owns day-2 checks.

Use the Connect page for topology decisions and the Operate page for day-2
manual work; this page is the runnable example bridge between them.
