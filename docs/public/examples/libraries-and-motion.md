# Libraries And Motion

Use this page when you want examples around reusable library code or motion
control concepts. The demo below is the first practical PLCopen Motion example;
read the library guide when you need the full supported subset.

You should leave with a concrete single-axis mental model: which function block
is being exercised, what the example proves, and where the library guide takes
over. Budget 10-20 minutes for the example read-through. Read
[PLCopen Motion](../develop/libraries/plcopen-motion.md) when you need
supported-surface detail before adapting the project.

Success means you can point to the axis command, expected state transition, and
validation step before changing the demo.

Do not treat the demo as hardware commissioning evidence; it is the library and
project-shape proof.
