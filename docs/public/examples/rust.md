# Rust Examples

Runnable projects with Rust in them, with no hardware. A Rust function block runs in the scan and
needs no Rust of your own: truST's toolchain builds the crate. A Rust service runs beside the runtime
as an ordinary Rust program, which you build with your own Rust.
