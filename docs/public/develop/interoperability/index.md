# Interoperability

Use this section when you are importing, exporting, or authoring against vendor ecosystems.

## Rule Of Thumb

- Start with PLCopen if the question is about XML import/export or portability.
- Start with CODESYS and TwinCAT if the question is about day-to-day Beckhoff/CODESYS-style authoring.
- Start with Siemens or Mitsubishi when you need concrete migration or style guidance for those ecosystems.
- Use Vendor Libraries when the source project depends on libraries that truST does not ship directly.
