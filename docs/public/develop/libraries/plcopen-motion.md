# PLCopen Motion

Use PLCopen Motion when:

- you want the standard motion-model terminology
- you want the truST-supported subset and examples

The guide below explains the motion-control vocabulary, the supported function
block surface, and the proof path from an example axis to project validation.
After reading it, you should know whether the shipped subset is enough for a
prototype, where to find the runnable single-axis demo, and which real hardware
behavior still belongs in commissioning.

Use the example page next when you want the smallest runnable motion-shaped
project before adapting your own axis logic.

Do not start here if you are still deciding whether a reusable library belongs
in a package or a project; use [Libraries](index.md) first.
