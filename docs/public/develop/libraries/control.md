# Control

Control is truST's PID library: `Control.PID` for P, PI, PD and PID loops with modes, limits and
anti-windup, `Control.LowPass` for filtering a signal, and optional structures for dead time, for a
plant that changes with its operating point, and for two loops that disturb each other.
