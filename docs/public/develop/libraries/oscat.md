# OSCAT

Use OSCAT when:

- the shipped package already covers the function family you need
- you want the truST-aligned compatibility notes for the imported surface

The guide below explains the supported import shape, the function families that
are useful today, and where the compatibility boundary sits. After reading it,
you should know whether OSCAT belongs in the project, which symbols you can
expect from the shipped surface, and which behavior still needs project-level
tests.

Use the examples page next when you want to see the library in a runnable
project rather than only reading the compatibility guide.

Do not start here if you are only trying to understand project layout; start
with [Libraries](index.md) or [Project Layout](../project-layout.md) first.
