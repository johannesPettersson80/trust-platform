# Operator Daily Checks

Use this page when you need the generic start-of-shift or periodic operator
checklist.

## Daily Checks

1. confirm the HMI loads
2. confirm the runtime shows healthy status
3. confirm no unexpected active alarms
4. confirm trends or KPIs are updating
5. record anything abnormal in the site runbook
