# Safety And Commissioning

If the plant question is about emergency stop handling, `e-stop` boundaries,
safe state, restart discipline, or commissioning sign-off, start here.

## E-Stop And Safe-State Boundary

Read the guide below before live plant use. After reading it, you should know
which safety claims truST does not make, what evidence to collect before
commissioning, and which site-owned procedures must exist outside the software.

Success means the team has a written safe-state boundary, a restart procedure,
an evidence bundle, and a sign-off owner before anyone treats the runtime as
part of a live plant workflow.

Use this page before I/O, deployment, or HMI operator rollout whenever a live
output or safe state is involved.
