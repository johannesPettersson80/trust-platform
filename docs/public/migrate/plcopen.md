# PLCopen

PLCopen is the open interchange path for XML import/export of Structured
Text projects. Ladder programs are not exchanged as PLCopen XML; they run as
their Structured Text companion.

| Question | Check |
| --- | --- |
| what survives import/export? | ST-complete compatibility |
| what applies to Ladder? | Ladder programs |
| is the migration complete? | build, validate, run, and inspect the generated project |
