# Agent API v1

This is the wire reference for `trust-runtime agent serve`.

Use it when you need exact request/response behavior instead of the higher-level
overview page. After reading it, you should know which methods are stable in v1,
what payload shape an agent must send, and how diagnostics or runtime state are
returned without going through the VS Code extension.

Success means a client can form a valid request, parse success and error
responses, and know when to use the higher-level overview instead of the wire
contract.

Use [Agent API overview](overview.md) first when you are choosing capabilities
rather than implementing the protocol.
