# Discovery And Pairing

Use this when you want runtimes to find each other on the network and
optionally establish trusted access. This is the local-network entry point for
multi-runtime systems before you commit to a longer-lived mesh or cloud shape.

Read this page when:

- peers are not fixed ahead of time
- you want discovery before manual endpoint wiring
- you need pairing/trust behavior explained
