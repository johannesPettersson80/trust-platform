# Enterprise Integration

## Choose The Right Path

- [Historian And Database](historian-and-database.md): time-series or database
  style ingestion and reporting
- [MES And ERP](mes-and-erp.md): batch/reporting/workflow integration with plant
  IT systems

## Rule Of Thumb

- if you need field/device communication, stay in [Connect](../index.md)
- if you need operator views or alarms, stay in [Operate](../../operate/index.md)
- if you need business-system exchange, start here
