# Empty simulator

The empty starter is the smallest runnable truST project.

- **First action:** Open this example folder in VS Code and press **Start** in the truST project view.
- **Expected result:** The Simulator runs the empty `Main` program; there are no process-image values or hardware devices to observe.
- **Simulation and hardware:** `io.toml` selects the simulated driver. This example needs no hardware and has no hardware wiring to commission.
- **truST surface:** Use the existing **Devices & Connections** runtime selection and **Live Values** entry points when exploring the simulator.
